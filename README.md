# Data-Cleaning-Analysis-Visualization-with-Excel
This assignment focuses on cleaning, analyzing, and visualizing E-commerce sales data using Excel. It includes formulas, VLOOKUP, Pivot Tables, statistics, charts, and a dashboard.
This assignment focuses on cleaning, analyzing, and visualizing an E-commerce sales dataset using Microsoft Excel. The dataset was organized into tables, missing and inconsistent data were handled, and irrelevant data was removed. Excel formulas such as SUM, AVERAGE, COUNTIF, IF, and TEXT were used for analysis. VLOOKUP was used to combine information from different tables. Pivot Tables and descriptive statistics were created to summarize the sales data. Finally, charts and an interactive dashboard were developed to visualize sales trends, category-wise sales, and region-wise sales.
	Description
  1	Imported and organized the E-commerce dataset into Excel tables.
  
  2	Checked all tables for duplicate records.
  
3	Handled missing values in Customer, Product and Sales tables.

4	Used median/category-based values and formulas to handle missing numerical data.

5	Removed the irrelevant Sub_Category column from Product_Dim.

6	Applied Excel formulas including SUM, AVERAGE, COUNTIF, IF and TEXT.

7	Used VLOOKUP to combine Customer, Product and Store information with sales data.

8	Created descriptive statistics including Minimum, Maximum, Mean, Median, Mode and Standard Deviation.

9	Created Pivot Tables for Region-wise, Category-wise and Monthly Sales analysis.

10	Created Line, Column and Bar charts for visualization.

11	Created an organized Dashboard with KPIs and charts.
